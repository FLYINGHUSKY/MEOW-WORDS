# 猫猫六级

一个以橘猫为主题的六级词汇学习网页。直接双击 `https://flyinghusky.github.io/MEOW-WORDS/` 即可使用，不需要安装依赖或启动服务器。

## 功能

- 按 0 / 1 / 2 / 4 / 7 / 15 / 30 天的节奏安排复习
- “忘记了 / 有点模糊 / 记住了”三档记忆反馈
- 选择“忘记了”的单词会留在今日到期列表，并自动加入本轮队尾再次复习
- 由 5,651 条六级原始词条合并而成的 3,991 个去重单词
- 单词和例句的浏览器英文发音
- 中文释义、助记提示和中英例句
- 今日任务、连续打卡、近 14 天活动和掌握度统计
- 六级词库搜索及学习状态筛选
- 每日新词目标设置
- 使用浏览器 `localStorage` 自动保存学习进度
- 支持游客模式，以及用户名＋密码账号登录和跨设备进度同步
- 桌面端、平板和手机自适应布局
- 学习页猫咪会轻轻左右摆头，并按本地日期每天自动更换造型
- 学习页陪学猫咪使用白色圆形背景，并随每日素材切换
- 品牌标题使用橘猫头像标识
- 左侧导航使用纯色背景，右侧主内容使用横版猫咪海报并按本地日期每日轮换
- 单词卡片学习页会自动启用浅色背景蒙版，其余页面保持原图显示

## 使用

1. 用 Edge、Chrome 或其他现代浏览器打开 `https://flyinghusky.github.io/MEOW-WORDS/`。
2. 点击“开始今日学习”。
3. 先回忆词义，再翻卡并按真实记忆情况评分。
4. 下次打开网页时，系统会自动找出到期单词。

发音由浏览器的语音合成功能提供；不同系统中的音色可能略有区别。

## 启用用户名登录

网页默认以游客模式运行；完成以下配置后才会开放注册与登录：

1. 在 [Supabase](https://supabase.com/) 创建项目。
2. 打开 Authentication → Providers → Email，保持 Email 登录启用，并关闭 Confirm email。用户名账号不绑定真实邮箱，因此无法接收确认信或找回密码。
3. 打开 SQL Editor，执行项目根目录中的 `supabase-setup.sql`，创建带 Row Level Security 的用户进度表。
4. 在项目设置的 API 页面复制 Project URL 和 Publishable key，填入 `supabase-config.js`。不要把 `service_role` key、数据库密码或其他私密密钥写进网页。
5. 将新增和修改的文件推送到 GitHub，GitHub Pages 会自动重新部署。

游客记录保存在原有的 `localStorage` 中；新账号注册成功时会把当前游客进度合并到账号。已登录用户的本地缓存按用户 ID 隔离，并同步到 Supabase。

## 词库来源

完整词库数据来自 [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary) 的六级正序 sentence 数据。原始数据中同一拼写可能按不同义项重复收录；网页构建时合并了 5,651 条记录，最终得到 3,991 个不重复单词，并保留合并后的释义、音标及双语例句。项目中可运行 `scripts/build-vocabulary.cjs` 重新生成浏览器数据文件。
